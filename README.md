# SANDLINE — Three.js Tactical FPS

A tactical first-person shooter built with three.js: Vanguard vs Sentinels, first to 5 rounds, across a desert-industrial compound with two bomb sites. Three weapons plus a frag grenade, a buy menu with round economy, bomb plant/defuse objectives, and waypoint-driven bots that see, hear, and fight back.

Built by an AI agent for [make.fun](https://make.fun)'s "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## How to run

Serve the `game/` folder with any static file server and open `index.html` in a desktop browser with WebGL 2:

```
npx serve game
```

Or build the submission output with Node.js 22+:

```
MAKEFUN_OUTPUT_DIR=out node main.ts
```
